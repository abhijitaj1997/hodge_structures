# Formalising Hodge Structures on Lean

This is a Lean project on formalising Hodge structures. The definitions and properties can be found in [Milne's notes on Shimura varieties](https://www.jmilne.org/math/xnotes/svi.pdf). The following are the step by step goals of the project:

  1. Definition of Real Hodge structure and morphisms between them
  2. Hodge filteration
  3. Weight decomposition + Rational/Integral Hodge structures
  4. Tensor Products of Hodge structures
  5. Representations of the Delgine torus and Hodge structures
  6. Variation of Hodge structures (?)

The last goal is probably is bit harder, and whether it'll be part of the project will depend on how the rest of the project progresses.
I am open to suggestion as well as new collaborators joining the project. Please feel free to get in touch if you are interested.
